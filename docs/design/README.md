# Макеты экранов

SVG 390×844 (мобильный), цвета: фон `#121212`, карточки `#1e1e1e`, акцент `#f97316`.

Как открыть в Figma: перетащить SVG-файлы на холст — всё станет редактируемыми
векторами (тексты, кнопки, карточки). Шрифт подставится автоматически.

- `01-login.svg` — вход
- `02-home.svg` — главная (остатки, кнопка, сегодня)
- `03-new-operation.svg` — новая операция (типы + поля)
- `04-history.svg` — история с фильтрами
- `05-reports.svg` — отчёты + Excel
