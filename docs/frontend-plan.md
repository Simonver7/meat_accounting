# План разработки фронта

Мобильный веб (Next.js PWA, смартфон-first). Стиль: минимализм, тёмная тема + оранжевый акцент.
Бэкенд-ручки уже готовы (см. README.md).

## 0. Дизайн-система

- Фон `#121212`, карточки `#1E1E1E`, акцент `#F97316`, текст `#FFFFFF` / вторичный `#A1A1A1`.
- Только тёмная тема. Один шрифт, остатки крупно (32px+), остальное 14–16px.
- Один главный CTA на экран, цифры вместо графиков, нижний таб-бар: Главная / История / Отчёты.

## 1. Сетап

Next.js (App Router) + TypeScript + PWA (`manifest.json`, иконки 192/512, theme-color `#121212`).
API-base через `NEXT_PUBLIC_API_URL`. Деплой за тем же Nginx, что и бэк.

## 2. Авторизация

- `/login`: логин + пароль → `POST /auth/login`, токен в localStorage, 401 → русский текст.
- Гард: без токена всё редиректит на `/login`. Ролей нет.

## 3. Главная `/`

- Карточки остатков Филе / С кожей (`GET /stock`), кнопка `+ Новая операция`,
  «Сегодня» (`GET /reports?period=today`), ссылки на Историю и Отчёты.

## 4. Новая операция `/operations/new`

- Шаг 1: 1 из 5 типов. Шаг 2: только нужные поля (мясо, кг, дата по умолчанию
  сегодня, коммент; франшизе — селект из `GET /franchises?active_only=true`).
- `409 INSUFFICIENT_STOCK` — текст с доступным остатком, форма не сбрасывается.

## 5. История `/history`

- Список (`GET /operations`): дата, тип, мясо, кг, кто. Фильтры: дата, тип, мясо,
  франшиза, статус. Детали: правка (PATCH) / отмена (confirm), аудит
  (`/{id}/changes`): было → стало → кто → когда.

## 6. Отчёты `/reports`

- Пресеты День / Неделя / Месяц + свой период (`GET /reports`). Таблица по двум
  видам мяса: на начало, приход, вертель, списание, конвектомат, франшиза, на конец.
- Кнопка «Excel» (`GET /exports/excel` → скачивание).

## 7. Полировка

- Скелетоны, русские тексты ошибок из API как есть, проверка на 360px.
- PWA: установка на домашний экран. Офлайн — out of scope: показываем «Нет связи».

## 8. Не делаем (ТЗ §16)

Светлая тема, графики, остатки франшиз, мульти-точки, готовое мясо, роли,
нативное приложение, CRM.

## Порядок

Токены → Главная → Форма операции → История → Отчёты → PWA → деплой.
